# Third-party notices

The prebuilt WebAssembly artifacts in `prebuilts/` are compiled from more than
one project's code. This file records the notices those projects require. It
covers the artifacts as shipped; the license of this package's own source is in
`LICENSE`.

## nec2++ (GPLv2-or-later)

The solver itself. Tim Molteno, <https://github.com/tmolteno/necpp>.

`COPYING` in that project is the GPLv2 text, but its source headers read
"either version 2 of the License, or (at your option) any later version", so it
is GPL-2-or-later and may be combined with the GPLv3 that governs this package.

The corresponding source is the `third_party/necpp` submodule, pinned to an
exact commit and shipped in the published tarball; `build.sh` reproduces the
artifacts from it. See `third_party/necpp/COPYING` for the license text.

## Eigen (MPL-2.0)

nec2++ bundles Eigen under `third_party/necpp/src/eigen/` and uses it for the
linear algebra, so the compiled artifacts contain Eigen code. Eigen is offered
under the Mozilla Public License 2.0, whose terms are compatible with the GPL
that governs the combination. The source ships with the submodule, which is
what MPL-2.0 requires for the covered files.

## Emscripten runtime (MIT)

`nec2pp.mjs` and `nec2pp-inline.mjs` are generated by Emscripten 6.0.3 and
embed its JavaScript runtime support code, including the embind glue. The
`.wasm` links Emscripten's musl-derived libc and its C++ standard library
support. Emscripten is offered under the MIT license (and the University of
Illinois/NCSA Open Source License); its terms are compatible with the GPL that
governs the combination.
